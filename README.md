# Dumb GrapheneOS - frameworks/base

Fork of GrapheneOS `platform_frameworks_base` with custom modifications.

## Key Changes

- `PackageAllowlist.java` - App installation whitelist enforcement
- `PackageInstallerService/Session` - Installation hooks
- `GosPackageStatePermission` - Package state permissions
- GmsCompat DCL exemptions
